PyGMT-Plotting Skill 手册

发表级科研制图的模板化生产系统 —— 模板 · 风格 · 自检，三位一体

本 skill 把日常科研制图（InSAR 形变场、地震目录、GPS 速度场、缠绕干涉图、剖面、多面板组图） 收敛成一套经实测验证的生产线：六个开箱即跑的模板脚本 × 六种一键切换的视觉风格 × 一个强制的交付前自检回路。设计哲学四条：

  • 模板优先——常见图型从模板复制起步，不从零手写（实测手写路径 20+ 次迭代还常翻车，模板路径 5 次收工）；
  • 风格即参数——投稿/幻灯/海报/暗色，改一行 STYLE 整图换装；
  • 交付必自检——渲染后读图过清单，压盖/裁切/缺件/数据锚点逐项核过才算完成；
  • Token 节制——默认只加载主文档+模板，其余六份文档按症状触发、每会话至多一次。

安装位置 ~/.claude/skills/pygmt-plotting/；质量基线：GMT 6.6.0 / PyGMT 0.17.0， 经十轮共 24 次盲测迭代打磨（附录 A）。

第一章快速开始

1.1 三种用法

① 自然语言（推荐）：直接向 Claude 描述图，skill 自动触发并路由：

你说得到
"画一下这个事件的 LOS 形变图"displacement_map 模板 + house 风格
"余震目录加 beachball，投稿用"seismicity_map + journal 风格
"组会要缠绕干涉图，深色 slides"wrapped_phase_map + dark 风格
"GPS 速度场，海报，经典制图风"velocity_field_map + classic 风格

② 显式调用：/pygmt-plotting —— 想强制以本规范重画或审查现有图时用。

③ 直接跑模板（不经 Claude）：

python3 ~/.claude/skills/pygmt-plotting/scripts/displacement_map.py

每个模板自带合成 demo 数据、离线可跑；打开脚本改顶部 CONFIG 块即是你的图。

1.2 最小自写示例

import sys, os
sys.path.insert(0, os.path.expanduser("~/.claude/skills/pygmt-plotting/scripts"))
from style_presets import style, panel_label, colorbar, coast_colors
import pygmt

fig = pygmt.Figure()
with style("house"):                       # 或 journal/classic/minimal/presentation/dark
    fig.basemap(region=[-120,-119,35,35.8], projection="M12c",
                frame=["WSne", "xaf", "yaf"])
    fig.coast(**coast_colors("house"))
    pygmt.makecpt(cmap="vik", series=[-30, 30])
    fig.plot(x=lon, y=lat, fill=v, cmap=True, style="c0.18c", pen="0.25p,black")
    panel_label(fig, "A")
    colorbar(fig, "LOS displacement (mm)")
fig.savefig("map.png", dpi=300)

第三章风格系统

六种风格 = 六套 pygmt.config 预设 + 配套的 panel label / 色标 / 海陆配色。 同一份数据，换一个词换一身衣服：

house默认。plain 细框 + Helvetica 9p，日常科研图
journal投稿终稿：字号线宽收一号，适配单栏 8.5 cm
classicGMT 经典黑白花边框 + ddd:mm:ss，学位论文/挂图
minimalAvantGarde 灰调浅网格，网页/现代简洁
presentation全部大一档粗一档，后排也看得清
dark深页底白字，深色幻灯/海报原生融入

场景路由：幻灯→presentation ｜ 深色幻灯/海报→dark ｜ 投稿→journal ｜ "经典制图"→classic ｜ 网页→minimal ｜ 其余→house。用户点名永远优先。

单图微调不必新建风格：style("house", MAP_FRAME_PEN="1.2p,black") 任意覆盖。 所有风格保留三条硬规：W/S 单侧注记、底部水平色标带单位、深度轴正值向下。dark 的专属注意事项 （海陆配色、CPT 选择、别开透明导出）见 STYLES.md。

第四章出图规范（House Rules）

  • 框：MAP_FRAME_TYPE="plain"、1p 黑；永不重复画框（subplot/inset 已画就不再传 frame）。
  • 注记：只在左 (W) 下 (S) 两边 → frame=["WSne", ...]；标题必须并入边框项 "WSne+tTitle"（GMT 6.6 分开写会报错）。
  • 面板字母：大写、无括号、白底方框，左上角等距。
  • 色标：水平置底带单位；diverging 用 vik 且零点居中对称；sequential 用 inferno/roma；缠绕相位必须 cyclic（romaO）。
  • 深度轴正值向下：负高度投影 "X12c/-4c"（3D 用 zsize="-3c"），永不用负数据造"向上为正"。
  • 防 moiré：条纹/斑点栅格的渲染像素数 ≥ 网格列数（单面板 ≥16 cm @400 dpi）；反向也成立——过粗网格出马赛克，≤1° 区域用 15s/03s 地形。
  • 真实地名用真地形：load_earth_relief（本地缓存、无需联网认证），严禁合成 DEM 冒充。

第五章QC 自检回路

savefig→ 读缩略图→ 六类清单逐项核→ 批量修复→ 复渲复核→ 对照原话核需求→ 交付
类别典型条目（每条都来自真实翻车）
压盖色标不压轴标签（笛卡尔面板 offset≥1.4c）；相邻面板刻度不相连；标注互不叠
裁切无文字被框切半；地图充满 region 不悬浮
缺件每支矢量都有箭头头；经纬注记齐全；色标有单位
冗印标签不印引号；无双框；连续场无意外分级色带
布局inset 叠图角内不外漂；面板等宽；共享色标居中
数据锚点条纹数≈位移÷(λ/2)；箭头↔参考尺同量级；方位角 ve=V·sin az；剖面峰值≈已知海拔

Token 纪律：每轮只读一次缩略图（sips -Z 800）；一次收集全部缺陷一次改完， ≤3 次渲染；QC 只重渲染不重跑数据；清单全文每会话读一次，后续凭记忆执行。

第七章疑难速查（GOTCHAS 精选十坑）

  1. frame 标题分开写报错（GMT 6.6）：["WSne","af","+t标题"] ✗ → ["WSne+t标题","af"] ✓
  2. velo/meca 0.17 改名：uncertaintyfill / compressionfill / extensionfill 无下划线，旧名硬报错（plot_longitude 类保留下划线）。
  3. velo 矢量 +n 双陷阱：纸面单位报错；+n8q 不报错但所有箭头头静默消失。velo 里省略 +n，用 VSCALE 保短矢量。
  4. 散点直喂 xyz2grd 出竖条纹：它不插值。散点→网格走 blockmean → surface。
  5. 标签引号被印出来：frame='y+l"Depth (km)"' 的引号会上图，直接写不加引号。
  6. grdview 真实 DEM 用 zscale 画布爆炸：用 zsize="3c" 定死总高。
  7. 缠绕相位平滑出灰带：必须 cyclic 色表 + interpolation="n"。
  8. inset 双框/无注记：inset 自带默认框，别再画；inset 内注记被抑制，需要注记改 shift_origin。
  9. session CPT 被覆盖：多色标图每面板紧贴 makecpt→grdimage→colorbar，或存文件引用。
  10. 地形分辨率两头翻车：过细→moiré；过粗→马赛克馒头山。≤1° 区域 15s/03s。
